# UX blueprint

## Desktop
Three-column workbench: source examples and drawing mode, central mathematical Canvas with playback, Fourier settings and error readout. Dark graphite visual design, teal animated tracing, muted blue original guide and circles.

## Mobile
Central canvas comes first, controls stack below, pointer capture supports mouse/touch/stylus, drawing mode disables touch scrolling on the Canvas only, range controls remain labelled and keyboard accessible.

## Phase 1 interaction
Preset buttons choose circle, square or flower; custom drawing starts a pen-down stroke; optional closure setting; releasing mouse/touch fits the stroke; visible help text describes the state. Pause/play and restart/seek should affect live animation. Toggle original, circles and trace separately.

## Later interaction
Import and contour preview, path-order editor, frequency spectrum with magnitude/phase, numeric RMSE vs harmonic budget, side-by-side comparison, image/SVG/CSV/video export and guided lesson cards.

## Important
Do not display fake upload/export functionality. All visible controls must work. Exact reference-site parity is **not** claimed.
