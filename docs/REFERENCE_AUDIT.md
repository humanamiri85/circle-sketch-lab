## When evaluating the reference later
- Desktop/mobile screenshots and navigation behavior
- Input controls, supported file types and size limits
- Contour extraction and multi-stroke path order
- Fourier convention, animation and harmonic budget semantics
- Export formatting, formulas, audio/video browser compatibility
- Premium/payment/account functionality, which likely needs backend
- Ownership of source code, branding, illustrations and third-party dependencies

Never claim reference code or images were copied. No scraping/private services or unlicensed brand assets.
